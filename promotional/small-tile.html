📸 How to capture this image:

1. Open this file in Chrome
2. Press F11 for fullscreen
3. Press F12 to open DevTools
4. Click the device toolbar icon (or Ctrl+Shift+M)
5. Set dimensions to exactly 440 x 280
6. Right-click on the purple tile → "Capture node screenshot"
