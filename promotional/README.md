# Promotional Images for Chrome Web Store

This folder contains templates for creating promotional images for the Chrome Web Store listing.

## Required Images

### 1. Small Tile - 440x280 pixels
**File**: `small-tile.html`

**How to capture**:
1. Open `small-tile.html` in Chrome
2. Press `F12` to open DevTools
3. Press `Ctrl+Shift+M` to toggle device toolbar
4. Set dimensions to **440 x 280**
5. Right-click on the purple tile
6. Select "Capture node screenshot"
7. Save as `small-tile-440x280.png`

### 2. Marquee - 1400x560 pixels
**File**: `marquee.html`

**How to capture**:
1. Open `marquee.html` in Chrome
2. Press `F12` to open DevTools
3. Press `Ctrl+Shift+M` to toggle device toolbar
4. Set dimensions to **1400 x 560**
5. Right-click on the banner
6. Select "Capture node screenshot"
7. Save as `marquee-1400x560.png`

## Quick Capture Method

Both HTML files include visual instructions. Simply:
1. Double-click the HTML file to open in your default browser
2. Follow the on-screen instructions
3. The templates are designed to be pixel-perfect for Chrome Web Store requirements

## Customization

Feel free to edit the HTML files to:
- Change colors
- Update text
- Modify the mockup content
- Add your own branding elements

The current design uses:
- **Primary gradient**: Purple to indigo (#667eea to #764ba2)
- **Font**: Inter (loaded from Google Fonts)
- **Theme**: Modern, clean design matching your extension's UI

## Notes

- Images must be PNG or JPEG format
- Chrome Web Store recommends high-quality, clear images
- The small tile appears in search results
- The marquee appears on your extension's detail page when featured
